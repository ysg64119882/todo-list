# 나의 할 일 (TodoList Web App)

하루의 할 일을 빠르게 추가하고, 완료하고, 정리할 수 있는 한국어 개인용 TodoList 웹애플리케이션입니다.  
디자인 시스템 명세(`DESIGN.md`) 및 웹 접근성 지침(WCAG 2.1 AA)을 준수하여 제작되었습니다.

---

## 1. 주요 기능

1. **할 일 추가**:
   - Enter 키 또는 "추가" 버튼으로 등록
   - 앞뒤 공백 자동 제거 및 빈 문자열/공백 차단
   - 최대 200자 제한 및 실시간 글자 수 카운터 표시
   - **한글 IME 조합 대응**: 한글 입력 중 Enter 키 입력 시 중복 등록되거나 원치 않게 전송되지 않도록 방어
   - 등록 후 입력창 초기화 및 자동 포커스 유지
   - 최신 항목이 맨 위에 위치하도록 정렬

2. **완료 상태 관리**:
   - 체크박스 또는 할 일 텍스트 클릭으로 완료/미완료 토글
   - 완료 항목에 명확한 취소선 및 저대비 색상 적용 (버튼 영역의 접근성 대비는 유지)
   - 실시간 진행률(0~100%) 및 완료/전체 개수 표시 (할 일이 0개일 때 0% 안전 처리)

3. **인라인 내용 수정**:
   - 각 항목의 수정(✎) 버튼으로 인라인 편집 시작
   - Enter 키 또는 저장(✓) 버튼으로 저장, Esc 키 또는 취소(✕) 버튼으로 취소
   - 빈 문자열 저장 차단 및 유효성 오류 안내
   - 저장/취소 후 기존 수정 버튼으로 포커스 자동 복귀

4. **개별 삭제 및 실행 취소 (Undo)**:
   - 각 항목의 삭제(🗑) 버튼으로 즉시 삭제
   - 하단에 실행 취소 스낵바 알림 제공 (`role="status"`, `aria-live="polite"`)
   - "실행 취소" 클릭 시 원래의 ID, 내용, 완료 상태, 생성일시 및 원래 목록 순서(index)로 완벽 복원
   - **연속 삭제 정책**: 빠른 연속 삭제 시 혼동을 방지하기 위해 **가장 최신에 삭제된 1건**이 실행 취소 대상이 됩니다.

5. **상태 필터 및 검색**:
   - 필터: `전체` / `진행 중` / `완료` (`aria-pressed` 지원)
   - 실시간 검색: 대소문자 무관 부분 문자열 검색 및 원클릭 검색어 초기화(✕)
   - 필터와 검색 조건의 교집합 적용
   - 빈 상태 구분 안내 (전체 없음, 진행 중 없음, 완료 없음, 검색 결과 없음)

6. **완료 항목 일괄 삭제**:
   - 완료된 항목이 없으면 버튼 자동 비활성화(`disabled`)
   - 클릭 시 확인 모달 대화상자(`<dialog>`) 제공 ("완료한 할 일 N개가 삭제됩니다.")
   - 취소 버튼 기본 포커스, 키보드 Esc 닫기 및 배경 클릭 취소 지원
   - 대화상자 종료 시 호출 버튼(또는 입력창)으로 포커스 복귀

7. **데이터 자동 저장 및 안전성**:
   - 브라우저 `localStorage` 기반 무중단 자동 저장
   - 스키마 버전(`schemaVersion: 1`) 포함 및 엄격한 페이로드 유효성 검사
   - JSON 파싱 오류나 지원하지 않는 상위 버전 감지 시 기존 데이터를 덮어쓰지 않고 보호하며 안내 배너 노출
   - 저장 실패(용량 초과 등) 시에도 앱 상태를 메모리에 유지하여 작업 연속성 보장

## 2. 저장 방식 및 제한사항

- **저장 범위**: 이 앱의 데이터는 **현재 사용 중인 웹 브라우저의 로컬 저장소(`localStorage`)에만 저장**됩니다.
- **클라우드 동기화 미지원**: 별도의 서버 백엔드, 사용자 계정, 로그인 기능 및 클라우드 원격 백업을 제공하지 않습니다.
- **브라우저 캐시 주의**: 브라우저의 쿠키/사이트 데이터를 완전 삭제하거나 시크릿 창(Incognito)을 닫을 경우 데이터가 초기화될 수 있습니다.
- **다중 탭 동기화**: 본 버전은 단일 탭 사용에 최적화되어 있으며, 여러 탭에서 동시에 편집할 경우 마지막으로 쓰기를 수행한 탭의 데이터로 덮어씌워질 수 있습니다.

## 3. 실행 및 빌드 방법

### 요구 환경
- Node.js 18.0.0 이상
- npm 9.0.0 이상

### 설치
```bash
npm install
```

### 로컬 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:5173`으로 접속합니다.

### 단위 및 컴포넌트 테스트 실행
```bash
npm run test
```
Vitest 기반의 21개 단위/컴포넌트/접근성 테스트가 실행됩니다.

### 프로덕션 빌드 및 미리보기
```bash
npm run build
npm run preview
```
`dist/` 폴더에 최적화된 정적 에셋이 생성되고 미리보기 서버가 구동됩니다.
